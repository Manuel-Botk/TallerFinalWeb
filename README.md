# Asistente del DM

Herramienta interactiva para Dungeon Masters de Dungeons & Dragons 5e.

## Enlaces

- **Aplicación web (Vercel):** [https://taller-final-web.vercel.app/](https://taller-final-web.vercel.app/)
- **Descargar APK (Android):** ver la sección [Releases](../../releases)

## Funcionalidades

- **Bestiario:** consulta, búsqueda y paginación de monstruos con sus estadísticas (AC, HP, CR).
- **Generador de botín:** monedas y objetos aleatorios según el nivel de desafío del monstruo derrotado.
- **Bandeja de dados:** d4, d6, d8, d10, d12, d20 y d100 con animación e historial.

## Tecnologías

- React
- Vite
- JavaScript
- CSS (Mobile-First)
- CapacitorJS (empaquetado Android)
- API pública: [D&D 5e API](https://www.dnd5eapi.co/api/)

## Ejecutar en local

```bash
npm install
npm run dev
```

## Compilar
